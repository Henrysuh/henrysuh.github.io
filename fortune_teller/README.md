# 🔮 AI 사주 만세력 & 마스터 프롬프트 연구소

정밀 명리학 연산 엔진과 AI(LLM) 프로젝트를 연결해 주는 **서버리스 웹 애플리케이션**입니다.  
**GitHub Pages**를 통해 100% 무료로 호스팅되며, 브라우저 내부에서 0.01초 만에 사주 8글자, 십신, 12운성, 신살, 대운을 오차 없이 계산합니다.

---

## ✨ 주요 기능

1. **정밀 만세력 연산 엔진 (JavaScript)**:
   - 24절기(절입시각) 및 60갑자 모듈러 연산 기반의 정밀 사주 8글자 산출
   - 한국 표준시 시차 보정(서울 127.5도 기준 -30분) 지원
   - **지장간(여기·중기·본기) 3단계 및 천간 투간(透干)** 정밀 분석
   - **천간합충 및 지지 육합·삼합·방합·육충·형(삼형)·파·해** 동적 상호작용 자동 감지
   - 십신(10신), 12운성(장생~양) 및 주요 신살(도화, 역마, 화개, 천을귀인 등) 분석
   - 10년 주기 대운 흐름표(순행/역행 및 대운수) 및 **세운(歲運)** 타임라인 결합

2. **표준 11단계 전문가용 마스터 프롬프트 생성**:
   - **[0단계] 만세력 데이터 무결성 독립 검증**: AI가 4주 간지 및 대운수를 선행 역검증
   - **사후 끼워맞추기 방지(Anti-Hindsight)** 원칙 탑재: 사후 왜곡 방지 및 객관적 명식 우선 선언
   - **정통 명리학 11단계 파이프라인**: `만세력 검증 → 월령/통근/투간 → 신강신약 → 조후 → 격국 → 용희기신 → 십신 생극 → 합충형파해 → 12운성/신살 → 대운×세운 → 현실 행동전략`
   - **현대적 행동 전략**: `일하는 방식 6대 모델`(조직형/사내전문가/리더/프로젝트형/고객접점/창업) & `행동 재무학 관점의 4단계 금융 심리 분석` 탑재

3. **사주 분석 기념 리포트 다운로드**:
   - `.md` (마크다운) 및 `.txt` (텍스트) 파일로 1초 만에 내보내기 지원
   - 인쇄 및 PDF 저장 지원

4. **Claude / ChatGPT Project 활용 가이드**:
   - Claude Projects 및 ChatGPT Custom GPTs에 사주 데이터를 영구 등록하는 방법 안내
   - 직업/커리어, 재물/투자, 연애/결혼, 멘탈/개운법 등 카테고리별 마스터 질문 모음집 제공

---

## 🔒 보안 & 비용 안내

- **서버 비용 0원**: 백엔드 서버 없이 GitHub Pages 정적 호스팅으로 구동됩니다.
- **API 비용 0원 & 보안 100%**: 서버에 API Key를 두지 않고, 사용자가 생성된 프롬프트를 자신의 ChatGPT / Claude / Gemini에 붙여넣어 사용하므로 API 과금 및 탈취 위험이 전혀 없습니다.
___

  ### 🔒 데이터 처리 및 소멸 원리

  1. 서버 전송 0% (100% 클라이언트 사이드 구동)
      • 백엔드 서버나 데이터베이스(DB), 외부 통신 API가 전혀 존재하지 않습니다.
      • 입력하신 이름, 성별, 생년월일시는 네트워크를 통해 외부 어디로도 전송되지 않습니다.
  2. 디스크 비저장 (순수 휘발성 메모리/RAM 처리)
      • 브라우저의 런타임 메모리(자바스크립트 RAM 변수) 위에서만 계산하고 화면에 즉시
      뿌려줍니다.
  3. 새로고침(Refresh) 및 탭 종료 시 즉시 완전 소멸
      • 브라우저를 새로고침(F5, Ctrl + R)하거나 창을 닫는 즉시 메모리가 초기화되어 입력했던
      모든 개인정보와 연산 결과가 흔적도 없이 완전히 사라집니다.

  ___
  ### 💡 프라이버시 관점에서의 장점

  • 생년월일시와 같은 민감한 개인정보가 서버 로그나 기기 디스크에 남지 않으므로, 개인정보 유출
  위험이 원천 차단된 가장 안전한 무기록(Zero-Trace) 프라이버시 구조입니다.
