# 🔮 AI 사주 만세력 & 마스터 프롬프트 연구소

정밀 명리학 연산 엔진과 AI(LLM) 프로젝트를 연결해 주는 **서버리스 웹 애플리케이션**입니다.  
**GitHub Pages**를 통해 100% 무료로 호스팅되며, 브라우저 내부에서 0.01초 만에 사주 8글자, 십신, 12운성, 신살, 대운을 오차 없이 계산합니다.

---

## ✨ 주요 기능

1. **정밀 만세력 연산 엔진 (JavaScript)**:
   - 24절기(절입시각) 및 60갑자 모듈러 연산 기반의 정밀 사주 8글자 산출
   - 한국 표준시 시차 보정(서울 127.5도 기준 -30분) 지원
   - 십신(비견·겁재·식신·상관·편재·정재·편관·정관·편인·정인) 자동 매핑
   - 12운성(장생~양) 및 주요 신살(도화, 역마, 화개, 천을귀인, 괴강, 백호, 양인 등) 분석
   - 10년 주기 대운 흐름표(순행/역행 및 대운수) 시각화

2. **LLM 맞춤형 마스터 프롬프트 원클릭 복사**:
   - 계산된 사주 데이터를 정밀하게 포맷팅하여 ChatGPT, Claude, Gemini에 바로 붙여넣을 수 있는 프롬프트 자동 생성
   - 미신적 공포를 배제하고 현대 심리학과 커리어 코칭 관점으로 풀이하도록 설계된 고품질 프롬프트

3. **사주 분석 기념 리포트 다운로드**:
   - `.md` (마크다운) 및 `.txt` (텍스트) 파일로 1초 만에 내보내기 지원
   - 인쇄 및 PDF 저장 지원

4. **Claude / ChatGPT Project 활용 가이드**:
   - Claude Projects 및 ChatGPT Custom GPTs에 사주 데이터를 영구 등록하는 방법 안내
   - 직업/커리어, 재물/투자, 연애/결혼, 멘탈/개운법 등 카테고리별 마스터 질문 모음집 제공

## 🚀 GitHub Pages 1분 배포 방법

1. 본 저장소를 GitHub에 `git push` 합니다.
2. GitHub 저장소의 **[Settings]** 탭으로 이동합니다.
3. 좌측 메뉴에서 **[Pages]**를 클릭합니다.
4. **Branch** 설정에서 `main` (또는 `master`) 브랜치를 선택하고 폴더는 `/ (root)`로 지정한 뒤 **[Save]**를 누릅니다.
5. 1~2분 뒤 생성되는 **`https://<사용자아이디>.github.io/<저장소이름>/`** 주소로 접속하면 즉시 서비스가 활성화됩니다!
